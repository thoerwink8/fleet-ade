# mirasim 全功能取舍稿（2026-11-21）

- 起因：需求方 2026-11-21 要求把 mirasim 的功能全部调研出来，判断 fleet-ade 要不要；mirasim 做了很多没必要的功能（agent 助手、多人协同），基础功能做得好的可以学。
- 材料：本机 mirasim 网页版逐页截图与 DOM（49 张图，设置 18 页全覆盖），安装包前端文案 12509 条；fleet-ade 现状按 `origin/main@2c727f3b75` 核对。mirasim 行为多从界面和文案反推，没有逐项实跑。

## 1. 结论

mirasim 的会话驾驶这一层（侧栏分组、会话页、输入框、自动化、额度、设置里的智能体、模型、网络）fleet-ade 大多已有，只学十处细节。消息、频道、通讯录、助手、事项、文档、应用发布、空间、计费、周榜整层不要。

## 2. fleet-ade 要做成什么

1. 一个人的指挥台，不是团队平台；活的源头在 GitHub（#122、#155，决定 0126）。
2. 只把要人动手的推到眼前，其余安静（#169、#113，决定 0121）。
3. 一群活跑在哪台机器、哪个仓、到了哪一步，看得见、能纠正（#99–#105、#170）。
4. 做减法：内部机制不上界面，每个字段先答帮人做什么决定（#162、#174、#117）。
5. 额度和花费心里有数，一个渠道用完能接着干（#155、#143、#84，决定 0128）。
6. 中文、好读、不卡：正文 14–15px、行高约 1.6，尺寸写 px（#156、#164，决定 0121；#146）。

## 3. 要做（按优先级）

1. 额度用完接着干（大）：按设置的渠道顺序换渠道带完整记录续跑，时间线留一行原因；下一个渠道要花新钱时不自动换、进「等你处理」；只跨渠道，不在同一家多账号间轮换。
2. 侧栏会话行补齐（中，并 #162、#176）：字段先答帮人做什么决定；目录不在了标红并进「等你处理」；仓分组显示「N 个 worktree 没有对话」；空会话折叠；100+ 会话滚动不卡。
3. 字号按 px 写（小）：`apps/web/src/index.css:136-147` 字阶现用 rem，浏览器默认 12px 时正文只有约 11.25px；改 px，正文三档 14/15/16。先核需求方当前浏览器字号。
4. 会话花费和机群计数（小，并 #143）：页头「上下文百分比 · 本会话花费」，读不到不显示；机群看板顶部三个计数和合计花费，可按今天/7 天/30 天筛。
5. 上下文占用构成（中）：按类别拆占用、压缩「释放 N%」，拿不到的类别不显示。第一步已拆成 #199（缓存命中与到期）。
6. 模型请求失败说清是哪条线路的问题（中）：代理拒绝、地区被封、证书被截、没应答；恢复后提示可重试。
7. 模型被换时提醒或停下（小，接 #84）：运行规则里一个开关，默认只提醒；时间线写「请求 A，实际 B」。
8. worktree 每天自动清理（小）：只自动清 PR 已合、无未提交改动、分支在远端的；其余列清单手动确认；留记录。
9. 全局唤起快捷键（小，只桌面）：叫出并定位到「等你处理」第一条，再按收起。
10. 自动化补 cron 和运行记录（小）：`packages/contracts/src/scheduledTask.ts` 加 cron，任务行显示上次结果、能打开每次运行的会话；MCP 也能建。模板部分已拆成 #200。
    另已开：#198 会话导出为 Markdown。

## 4. 不要

- 多人协同：消息、频道、私信、通讯录邀请、成员、角色、共写、@同事、布置空间、分享桌面、远程桌面（第 2 节第 1 条；PR #134 已删过一次）。
- agent 助手：协调者助手、新建助手、助手事项、事项里 @助手接手。fleet-ade 已有「指挥会话 + 子会话动态」，再加助手人设就是两个派活入口，且派活机制属于内部机制。
- 事项与 Issue 看板：源头是 GitHub issue。
- 文档、表格、PPT、资源库、应用发布：偏离编码驾驶舱，性能代价大。
- 空间、计费、充值、兑换码、周榜、徽章：自托管无计费，周榜鼓励多花钱。
- IM 进会话、灵动岛、托盘用量、截图增强、桌面级 Computer Use、会议转写、新手引导、公告、反馈、语言切换：答不出帮人做了什么决定，或与已有角标、全局唤起重叠。

## 5. 方向上定的三件（默认照推荐）

1. 额度用完只跨渠道接力，不在同一家多账号间自动轮换（账号条款风险；路由组已在网关做）。
2. 不做多会话并排分屏：指挥看子会话动态和机群看板，不并排盯过程；长会话首开已慢（#146）。
3. 不做跨会话「产物」页：交付以 PR 和回报为准。
