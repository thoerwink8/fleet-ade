# Open source licenses

Fleet ADE includes third-party software and adapted assets. To read their license and attribution
notices, open **Settings → Maintenance**, find **Open source licenses** under **Legal**, and
select **View licenses**.

The page lists the version when available, license identifier, and the parts of Fleet ADE that include
or use the item. Select a row to read the complete notice text. Use the search field to find a package,
version, license, or app component.
