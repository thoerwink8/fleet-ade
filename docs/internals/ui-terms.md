# 界面用词规范

本表定义 Fleet ADE 中文界面文案（按钮、标签、弹窗、提示、文档）的统一用词。代码内部标识符、设置键名、数据库值与开发者术语仍遵循 [词汇表](./glossary.md)，不在此限。

## 两档检查与看上下文判断规则

`pnpm ui:no-old-terms`（实现见 [ui-no-old-terms.ts](../../scripts/ui-no-old-terms.ts)）复用 `ui-no-english` 的 AST 扫描范围，跳过注释、日志、类型、对比常量、`data-*` 属性与 `searchTerms`。

1. **硬禁词**（出现于已清理目录的界面文案即报错）：词表只在脚本的 `HARD_BANNED_TERMS` 一处维护，上面表里「换掉」列中的旧词是它的来源。被服务端或别处按原文匹配的句子，在脚本的 `EXEMPT_TEXTS` 里按文件和原句登记，同一文件里新出现的旧词仍会报错。
2. **看上下文用词**（不进硬检查，改前逐处核对语义）：
   - `完成`：会话整理动作/状态用「标为完成」「取消完成」「已完成」；动作完成条件（如「上传完成后」「设置完成后」「段落已完成」）与「目标已完成」保留。
   - `环境` / `环境变量`：操作系统环境变量保留「环境变量」；Fleet ADE 宿主统一改为「电脑」。
   - `机器` / `设备` / `服务器` / `主机` / `引擎`：电脑硬件形态标签（如图标类型 `服务器`）、浏览器/手机「此设备」、外部 Git 主机域名等真实物理含义保留；指 Fleet ADE 服务所在计算机时改「电脑」或「后台服务」。
   - `代理`：指 HTTP/CLI 网络代理时保留「代理」；指 Codex/Claude 等 AI 代理时改「智能体」。
   - `中断`：用户主动点停统一用「停止」「已停止」；网络上传断开、应用重启导致的被动中止保留「中断」。
   - `混合`：指多个设置项值不一致时统一改「多项不同」；颜色或布局混合概念才保留。
   - `引用`：Git 分支/标签统一改「分支」「分支或标签」；引用消息内容/上下文芯片保留「引用」。
   - `对话` / `聊天` / `最近` / `未读`：指会话本体统一用「会话」；时间序（「最近一轮」「最近添加」）保留「最近」；操作动词「标为未读」保留「未读」，状态指示词统一改「有新结果」。
   - `token` / `凭据`：配对码统一「配对码」；API Token/OAuth 凭据或上下文词元上限（如「200,000 token」）按场景用「词元」「密钥」或「token」。

## 扫描范围

`scripts/ui-no-old-terms.ts` 的 `CLEANED_DIRS` 已覆盖整个 `apps/web/src`、`packages/client-runtime/src`、`packages/shared/src`。与服务端或历史持久化文本严格对照的少量例外只按句登记在 `EXEMPT_TEXTS` 并附来源文件与行号，不加整文件豁免。
