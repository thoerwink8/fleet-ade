# 跳过清单

关一 Linux 基线里 #17–#28 这 12 条失败。现象像是产品行为或浏览器超时，不是缺浏览器。每条单独跳过，文件里别的用例照跑。单号是本仓的问题。#31 是后来整包检查里多出来的一条。

- #17 `ChatMarkdown.browser.test.tsx` highlights a code block's own source when an earlier block of the same length was cached：高亮结果是 undefined，期望是源码字符串。
- #18 `DiffPanel.browser.test.tsx` expands an unloaded file on the first click with default collapse false：点 Expand 超时。同函数的 `true` 不在失败名单里，仍跑。
- #19 `AttachmentFilePreview.browser.test.tsx` toggles a Mermaid attachment between diagram and source through the lazy preview：点 Show rendered diagram 超时。
- #20 `AttachmentFilePreview.office.browser.test.tsx` keeps spreadsheet dates on their calendar day west of UTC：整例超过 15 秒。
- #21 `useInlineActionConfirm.browser.test.tsx` keeps a blocked merge action reachable without arming or performing it：整例超过 15 秒。`enable-auto-merge` 不在失败名单里，仍跑。
- #22 `CloudVoiceConfiguration.browser.test.tsx` cancelling a provider's setup keeps the current destination and writes nothing：点 Cancel 超时。
- #23 `CloudVoiceConfiguration.browser.test.tsx` enables the chosen provider only after a successful setup：点 API key 输入框超时。
- #24 `StorageSettings.browser.test.tsx` keeps a newer pending age open when an older first save fails：填写天数输入框超时。
- #25 `sheet-resize.browser.test.ts` requests current dimensions after resizing and scrolling away and back before a frame arrives：页面停在 Loading file。
- #26 `AntigravityInstallation.test.ts` explains that the linux-arm64 runtime needs 4 KiB pages when it aborts on a 16 KiB kernel：状态是 cancelled，期望是 failed。
- #27 `theme.test.ts` restores the previous theme when a re-publish fails to set：抛出 Unknown error: undefined。
- #28 `theme.test.ts` refuses to write when the settings file cannot be read：抛出 Unknown error: undefined。
- #31 `OpenCodeServerLedger.test.ts` stops an OpenCode server group left by a server that died：在 Linux 上按 darwin 观察时整例超过 60 秒。同名的 linux 观察仍跑。

#55–#108 是整包浏览器测试在这台高负载机器上超过 15 秒时开的单。对应用例不跳过，这些单不关。
